# 直接編集：第1段階（問題文のポイントのみ）

## 範囲

`questions.explanation_overview` の既存「編集」ボタンだけを直接編集へ切り替える。見出し・既存本文・試験用まとめ・選択肢・問題原文・画像・個人メモの保存先は変更しない。その他の欄は従来の編集画面を維持する。

- 表示中の `.line` を保ち、その本文領域内で編集。別のtextareaやプレビューは増やさない。
- 本文と装飾はメモリ上の下書き。保存ボタンまたはCmd/Ctrl+Sのみが質問テーブルを書き込む。
- キャンセルは本文・装飾のみを元に戻す。自動保存・localStorageへの下書き保存は実装しない。
- 太字 B、下線 U、取り消し線 Shift+S、マーカー Shift+M、強調色 Shift+A（いずれもCmd/Ctrl付き）。切り取り・コピー・すべて選択は標準操作を維持する。
- 画像はその場に残す。「画像を編集・追加」を開いたときだけ同じセクション内で既存の画像管理コントロールを利用する。画像操作は即時反映であり、本文キャンセルとは独立することを常時表示。
- 個人メモのDOM・保存処理・画像は作り直さない。

## 保存と競合

`explanation_formatting.explanation_overview` に従来形式の `{version,source_text,ranges}` を保存する。HTMLは保存しない。保存直前に本文と当該装飾の変更を確認し、最新の他欄装飾を保持して `updated_at` 条件付きで更新する。別の更新・認証変更・通信失敗では下書きを消さず、再保存または内容の退避を可能にする。

未保存状態ではアプリの移動操作と公開された移動関数に確認を入れる。保存中は二重送信と移動を止める。ページ再読み込みにはbeforeunloadを使用するが、モバイルOSによる強制終了時の通知は保証できない。

## 実装

`src/inline-overview-v1.js` を、`editor-build/package.json` の固定バージョンから `scripts/build-inline-overview.cjs` でビルドする。依存パッケージは `/tmp/qb-inline-build` にインストールし、Pagesへnode_modulesを含めない。生成された `inline-overview-v1.js` とライセンスを配信する。編集ライブラリをブラウザでCDNから取得しない。

既存共通スクリプトには書き換えを行わず、当該編集ボタンへの操作と編集対象のキーボード操作だけを限定的に受ける。画像クリック・個人メモ操作は横取りしない。編集中は既存装飾レンダラーの入力領域保護により本文の再装飾を避ける。

## 検証と退避

既存12単体テスト、既存Chromium/WebKit各25チェック、新規各18チェックを実行。新規チェックは直接編集・明示保存・キャンセル・文字装飾・改行・コピー＆ペースト・画像拡大・画像追加・メモ独立保存・未保存移動・保存競合・通信失敗を含む。DB/Auth/Storageは合成データを使用し、本番へのテスト書き込みはしない。

新UIを回避する診断用クエリは `?editor=classic`。アプリの本来のアクセス権は変更しない。完全に戻す場合は新scriptタグを外し、従来の本文・装飾データをそのまま表示できる。自動保存と他の編集欄への展開は未実装。
