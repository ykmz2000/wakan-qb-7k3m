# 選択肢の内容と採点の区別

statement_is_true は内容の正誤を表す nullable boolean。is_correct は従来通り設問の正答で、採点は変更しない。

回答・解説表示後、内容 true は緑、false は赤、null は中立。正答と選択は別のラベルで表示する。誤りを選ぶ問題でも正答と内容の誤りが両立する。

既存選択肢はすべて未設定のまま保持し、正答や修正文の有無から内容の正誤を推定しない。管理者の選択肢編集で明示設定する。文脈による肢は未設定を使う。

correction_text は「正しくすると」として既存解説内の選択肢直下に表示する。原文・修正文の自動生成や書き換えは行わない。既存の文字装飾編集で変更箇所を強調できる。
